# Game

TypeScript + HTML5 Canvas で作るブラウザゲームの土台です。
[Vite](https://vitejs.dev/) を使っています。

## セットアップ

```bash
npm install
```

## 開発

```bash
npm run dev      # 開発サーバーを起動（ホットリロードあり）
npm run build    # 型チェック + 本番ビルド（dist/ に出力）
npm run preview  # ビルド結果をローカルで確認
```

`npm run dev` を実行してブラウザで表示されるURL（通常 http://localhost:5173 ）を開くと、
WASD / 矢印キーで動かせる円が表示されます。

## ディレクトリ構成

```
src/
├── main.ts            エントリーポイント（キャンバスを取得してゲームを起動）
├── style.css          ページのスタイル
├── engine/            ゲームに依存しない汎用部分
│   ├── Game.ts        メインループ（固定タイムステップの更新 + 描画）
│   ├── Scene.ts       シーンのインターフェース
│   ├── Input.ts       キーボード入力の管理
│   └── Vector2.ts     2Dベクトル / 数値ユーティリティ
└── game/              このゲーム固有の部分
    ├── PlayScene.ts   メインのプレイ画面
    └── Player.ts      操作キャラクター（仮）
```

## 設計メモ

- **ゲームループ** は固定タイムステップ（60更新/秒）で `update` を回し、描画は毎フレーム行います。
  これにより当たり判定や移動の挙動がフレームレートに左右されません（`engine/Game.ts`）。
- **シーン** (`Scene`) を切り替える形にしてあるので、タイトル画面・ステージ・ゲームオーバーなどを
  追加しやすくなっています。`game.setScene(...)` で差し替えできます。
- ジャンルが決まったら `game/` 以下を育てていく想定です。`engine/` は基本そのまま再利用できます。

## 次にやれること（例）

- 敵やアイテムなどのオブジェクトを追加する
- 当たり判定を実装する（円同士・矩形同士）
- スコアやライフなどのゲーム状態を持たせる
- タイトル画面シーンを追加して `Scene` 切り替えを試す
- 画像（スプライト）や音を読み込む仕組みを足す
