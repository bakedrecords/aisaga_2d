# Game

メタルスラッグ系の**横スクロール・ランガン（run & gun）アクション**を
TypeScript + HTML5 Canvas（[Vite](https://vitejs.dev/)）で作っています。

タイトル → プレイ → ステージクリア／ゲームオーバー → リトライ、まで遊べます。

## セットアップ

```bash
npm install
```

## 開発

```bash
npm run dev      # 開発サーバーを起動（ホットリロードあり）
npm run build    # 型チェック + 本番ビルド（dist/ に出力）
npm run preview  # ビルド結果をローカルで確認
```

`npm run dev` を実行し、表示されるURL（通常 http://localhost:5173 ）を開いてください。

## 操作

| 操作 | キー |
| --- | --- |
| スタート | `Space` / `J`（タイトル画面） |
| 移動 | `A` / `D`、または `←` / `→` |
| ジャンプ | `Space` / `W` / `↑` |
| ショット | `J`（押しっぱなしで連射） |
| リトライ | `R`（結果画面） |
| タイトルへ | `T`（結果画面） |

## 遊び方

- ステージを左右に移動・ジャンプしながら**右端のゴール（旗）**を目指します。到達で **STAGE CLEAR**。
- 向いている方向に弾を撃って敵を倒します（撃破でスコア、クリアでボーナス）。
- 敵に接触するとHP減少（数秒の無敵あり）。HPが尽きると **GAME OVER**。
- 結果画面で `R` リトライ / `T` タイトルへ。

## ディレクトリ構成

```
src/
├── main.ts            エントリーポイント（タイトル画面から開始）
├── style.css          ページのスタイル
├── engine/            ゲームに依存しない汎用部分
│   ├── Game.ts        メインループ + シーン切り替え
│   ├── Scene.ts       シーン / SceneManager のインターフェース
│   ├── Input.ts       キーボード入力（押下／押しっぱなしの判定）
│   ├── Rect.ts        AABB（矩形当たり判定）
│   └── Vector2.ts     2Dベクトル / clamp
└── game/              このゲーム固有の部分
    ├── TitleScene.ts  タイトル画面
    ├── PlayScene.ts   ゲーム進行（生成・衝突・描画・スコア・勝敗）
    ├── Player.ts      自機（移動・ジャンプ・射撃・HP）
    ├── Enemy.ts       敵（プレイヤーに接近）
    ├── Bullet.ts      弾
    ├── Level.ts       ステージ（地面・足場・ゴール）
    └── Camera.ts      横スクロールのカメラ追従
```

## 設計メモ

- **固定タイムステップ**（60更新/秒）なので、移動・当たり判定がフレームレートに左右されません。
- **衝突解決は軸ごと**（横→縦）に行う、安定した2Dプラットフォーマーの定番方式です（`Player`）。
- **シーン**（`Scene`）を `game.changeScene(...)` で切り替えます。タイトル・プレイ・結果を分離。

## 次にやれること（例）
