# Game

メタルスラッグ系の**横スクロール・ランガン（run & gun）アクション**を
TypeScript + HTML5 Canvas（[Vite](https://vitejs.dev/)）で作っています。

全3ステージ・複数の敵・武器・ボス戦まで遊べます。

## セットアップ

```bash
npm install
```

## 開発

```bash
npm run dev      # 開発サーバーを起動（ホットリロードあり）
npm run build    # 型チェック + 本番ビルド（dist/ に出力）
npm run preview  # ビルド結果をローカルで確認
```

`npm run dev` を実行し、表示されるURL（通常 http://localhost:5173 ）を開いてください。

## 操作

| 操作 | キー |
| --- | --- |
| 移動 | `A` / `D`、`←` / `→` |
| ジャンプ | `Space` |
| ショット | `J` / `Z`（押しっぱなしで連射） |
| 照準（斜め撃ち） | `↑` / `↓` ＋ 進行方向（例: `↑`+`→` で右上） |
| しゃがみ | `↓`（被弾判定が下がり、頭上の弾を回避） |
| スタート / 次のステージ | `Space` |
| リトライ / タイトル | `R` / `T`（結果画面） |

武器は地面の**武器箱**で入手（`M`=マシンガン / `S`=ショットガン / `R`=ロケット）。
弾切れになると自動でピストル（無限）に戻ります。

## 内容

- **3ステージ**（ジャングル → 遺跡 → 要塞）。テーマ・地形・敵編成・多層パララックス背景が異なります。
- **残機制**: ミスしても残機が残っていればその場で復活（一時無敵）。残機が尽きるとゲームオーバー。
- **敵**: ウォーカー（接近）/ シューター（撃ち返す）/ フライヤー（飛行）/ **ブルート（中ボス・HPバー付き）** / **ボス**。
- **ボス**: 攻撃パターン（狙い撃ち扇／全方位バースト／高速3連）を循環し、HP4割以下で**強化フェーズ**（高速化・弾増）。
- **武器**: ピストル（∞）/ マシンガン / ショットガン（拡散）/ ロケット（爆発・範囲）。
- **アイテム**: 武器箱、回復（`+`）、スコア（`$`）。敵を倒すとドロップすることも。
- **地形ギミック**: 接触ダメージのトゲ。
- **演出**: 爆発・火花パーティクル、画面シェイク、被弾点滅。
- **サウンド**: Web Audio による効果音＋BGM（音声素材は不要。最初のキー入力で有効化）。

## ディレクトリ構成

```
src/
├── main.ts            エントリーポイント（タイトルから開始）
├── style.css          ページのスタイル
├── engine/            ゲームに依存しない汎用部分
│   ├── Game.ts        メインループ + シーン切り替え
│   ├── Scene.ts       シーン / SceneManager のインターフェース
│   ├── Input.ts       キーボード入力（押下／押しっぱなし／方向）
│   ├── Rect.ts        AABB（矩形当たり判定）
│   └── Vector2.ts     2Dベクトル / clamp
└── game/              このゲーム固有の部分
    ├── TitleScene.ts  タイトル画面
    ├── PlayScene.ts   ゲーム進行（生成・衝突・演出・スコア・勝敗・ステージ進行）
    ├── Player.ts      自機（移動・ジャンプ・しゃがみ・8方向照準・武器）
    ├── enemies.ts     敵（Walker / Shooter / Flyer / Boss）
    ├── Bullet.ts      弾（速度ベクトル・ダメージ・爆発）
    ├── Pickup.ts      武器箱
    ├── weapons.ts     武器データ
    ├── Particles.ts   パーティクル（爆発・火花）
    ├── Sound.ts       効果音 + BGM（Web Audio、共有インスタンス）
    ├── Camera.ts      横スクロール追従 + 画面シェイク
    ├── Level.ts       ステージ geometry（データから構築）
    └── stages.ts      ステージ定義データ
```

## 設計メモ

- **固定タイムステップ**（60更新/秒）で、移動・当たり判定がフレームレートに左右されません。
- **衝突解決は軸ごと**（横→縦）に行う、安定した2Dプラットフォーマーの定番方式（`Player`）。
- **シーン**（`Scene`）を `game.changeScene(...)` で切り替え、ステージ進行も新しい `PlayScene` への遷移で表現。
- **ステージはデータ駆動**（`stages.ts`）。面を増やすには配列に定義を足すだけ。
- `Sound` は `typeof window` を見て**非ブラウザ環境では無音**になり、テスト/ヘッドレスでも安全。
